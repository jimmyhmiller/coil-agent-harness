# Worker: Implementor

Coil is a low level lisp that you are going to implement everything in. There is a command `coil new` that will scaffold a project. If you check there you will see what coil code looks like and should be able to figure things out. coil has many helpful commands. Including `coil cheatsheet` and `coil guide` if you get lost. Only at as much as you need.

Your job is to implement this whole application as simply as you can. Try to make it mee the spec. Don't add things you don't need. Use any libraries and things you'd like. Coil has great ffi support.
