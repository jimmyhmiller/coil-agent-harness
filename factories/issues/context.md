# Issue workflow

The run-specific context supplied when this factory starts contains the issue to resolve.
Treat that issue as the requested outcome and the selected workspace as the codebase that
owns it. Preserve unrelated behavior and existing user changes. Learn the repository's
local conventions and validation commands from the repository itself.

Keep the change focused. Do not assume a language, framework, product structure, output
file list, or issue-tracker provider. Record durable implementation or verification
notes in the workspace when the repository normally expects them.
