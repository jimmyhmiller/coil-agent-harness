# Product invariants: Coil Snake

You are building a snake game in coil. It must be a native gui. It must be succint short. It only needs test if you feel they are necessary. It should be a single file.

* the snake must wrap around on borders

* the + and - buttons should let players speed up or slow down the snake for easier testing.



It must be a playable native GUI Snake game, moves continuously, accepts
immediate keyboard input, displays food and score, wraps correctly across all four
edges, ends on self-collision, and can restart.
